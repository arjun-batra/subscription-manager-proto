# Brand logos

`data.ts` in this folder is generated by `scripts/gen-brands.js` from the **Simple Icons 16.36.0**
npm package (`simple-icons`, https://simpleicons.org, https://github.com/simple-icons/simple-icons).
Nothing is downloaded at run time.

## Trademarks

CC0 covers the copyright in the icon files. It does not grant trademark rights. The names and
logos are trademarks of their owners; this app shows them only to identify the service a person
typed or picked, and does not imply any endorsement. Per Simple Icons' disclaimer, brands that
ask to be removed from Simple Icons should also be removed here (re-run `gen-brands.js` with a
newer Simple Icons and it will fail on any mark that is gone).

## Generic icons

The generic icons in `icons.ts` are Apple SF Symbols referenced by name and drawn by iOS through
`expo-symbols`; no symbol artwork is bundled.
