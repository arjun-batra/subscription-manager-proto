# Brand marks

`data.ts` in this folder holds SVG path data and brand colours for about 30 subscription
services, copied by hand (no download at run time) from **Simple Icons 16.36.0**
(npm package `simple-icons`, https://simpleicons.org, https://github.com/simple-icons/simple-icons).

Simple Icons is released under **CC0 1.0 Universal** (public domain dedication):
https://creativecommons.org/publicdomain/zero/1.0/. None of the icons copied here carries a
separate licence in the Simple Icons data file.

CC0 covers the copyright in the icon files. It does not grant trademark rights. The names
and logos are trademarks of their owners; this app shows them only to identify the service a
person typed, and does not imply any endorsement. Per Simple Icons' disclaimer, brands that
ask to be removed from Simple Icons should also be removed here.

Services with no mark here (for example Disney+, Prime Video, Microsoft, Adobe; their owners
asked Simple Icons to remove them) get a coloured first-letter tile instead.
